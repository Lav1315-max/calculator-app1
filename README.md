# 🧮 Calculator App

A simple and responsive calculator application built using HTML, CSS, and JavaScript. The project provides a clean user interface and supports basic arithmetic operations.

## 🚀 Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear/reset functionality
- Responsive user interface
- Interactive calculator buttons
- Real-time calculation display

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
